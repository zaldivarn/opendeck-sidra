Apple Music connection

Checking…

Adding to your library isn't part of MPRIS, so this key talks to Sidra's Apple Music page directly. Start Sidra with:

sidra --remote-debugging-port=9222 --remote-debugging-address=127.0.0.1

The port only listens on this machine. The README has a desktop-file override so the Sidra launcher always uses it.
